Digital Accessibility Training Exercises

Three courses, eight exercises. Every one runs in this browser, no install and no account. Work each with a keyboard first, then again with a screen reader.

Course 1 · Digital Accessibility Foundations

In module order. Log each finding with the page element, the barrier and the criterion it violates.

  1. Exercise 3.1 Module 3
    Auditing a real page

    Parks and events listing

    A city parks and events page with a filter panel, a card grid and a registration form. Find the barriers a keyboard-only visitor hits, then write up each one against the success criterion it violates.

    Part D, Services landing page. The Services page as published has five barriers: a hover-only menu, six identical links, light gray text and no focus outline. Find them, then open the corrected Services page and its disclosure of what changed and which criterion each fix satisfies.

    The four principles in practice

    Games

    Fiscal Year

  3. Exercise 6.1 Module 6
    Reading formatting without a code view

    Find the issues

    A department email that looks completely normal. Nine accessibility issues are embedded in it. Hover over any piece and the inspector tells you how it is actually built — the tag, the font, the contrast, the alt text. Decide from that description alone, flag what is broken, then open the answers. No dev tools required.

  4. Exercise 7.2 Module 7
    Testing with assistive technology

    Riverside Aquatics Center

    A city pool page built to pass WCAG 2.1 AA in full: skip link, landmarks, a dropdown menu, tabs, a modal dialog, an accordion, a data table, live status messages and a form that reports its errors properly. Nothing is broken on purpose. Run WAVE on it, work it with the keyboard alone, then read it with a screen reader to learn what each tool reports when a page is built correctly.

Course 2 · Writing Accessible Content

For the people who type pages into the CMS. No code view and no inspector: every page under review carries a Show how this page is built switch that reveals its real structure.

  1. Exercise 3.6 Course 2, Module 3
    Content structure

    Restructure a draft page

    Riverside Public Works has posted its leaf collection update. Every fact is right and the page is close to unusable. Read the headings alone, count the fake ones, sort nine facts out of one paragraph into a table, a list and a sentence, then rewrite the opening in plain language. Eight minutes, solo or in pairs.

    Links, images and color

Course 3 · Document & PDF Accessibility Fundamentals

For the person everyone forwards documents to. Answer each colleague, read what they say back, and clear the pile before Friday.

  1. Exercise 6.1 Course 3, Module 6
    Module assessment

    The Monday Pile

    You’re the person everyone forwards documents to. Ten messages arrive across one week, Monday through Friday, each from a colleague with a voice of their own. Every message carries two questions, twenty in total. Answer, then read the feedback: you’ll see what the colleague says back. What you get wrong bounces back, and shows up on the Friday recap as work waiting for you Monday morning. Sixteen of twenty gets you through the week. Retakes are unlimited and there’s no timer.
